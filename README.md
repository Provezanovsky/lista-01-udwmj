# Lista 01 - UDWMJ

## Pedra, Papel e Tesoura em JavaScript

Este projeto contém um jogo simples de **Pedra, Papel e Tesoura** desenvolvido em JavaScript.

### Funcionalidade

O programa solicita que o usuário escolha entre:

- pedra
- papel
- tesoura

Depois disso, o computador escolhe uma das três opções de forma aleatória usando `Math.random()`.

O programa compara as duas escolhas e informa o resultado:

- empate;
- vitória do usuário;
- vitória do computador.

Também existe uma validação para impedir opções diferentes de pedra, papel ou tesoura.

### Conceitos utilizados

- variáveis;
- arrays;
- `prompt()`;
- `alert()`;
- estruturas condicionais `if / else`;
- `Math.random()`;
- métodos de string como `toLowerCase()` e `trim()`.
